# Product Overview

This is an Amazon Alexa skill that provides information about Saturday Night Live (SNL) episodes. The skill allows users to ask when the next SNL episode will air and provides details about upcoming episodes.

## Core Functionality

- **Next Episode Query**: Users can ask "next episode" to get information about the next scheduled SNL episode
- **Today's Episode Check**: Determines if there's a new SNL episode airing today
- **Episode Details**: Provides host information and air dates for upcoming episodes

## Data Source

The skill integrates with the TVMaze API to retrieve real-time SNL show and episode information.

## Target Platform

Amazon Alexa voice assistant platform, deployed as an AWS Lambda function.
